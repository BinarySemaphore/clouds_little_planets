Symbols:
r, g, b, a = Red, Green, Blue, and Alpha (lin-color)
N = lin-depth when cloud alpha stops being zero (Near)
F = lin-depth when cloud sampling done, alpha at max (Far)
A = lin-depth when cloud 33% of alpha (midpoint-1/2)
B = lin-depth when cloud 67% of alpha (midpoint-2/2)
M1 = Normalized cubic P1
M2 = Normalized cubic P2
d = Composite native resolution lin-depth
t = Quadratic from cubic t term bound [0, 1]
b = Cloud blending value t for GLSL mix/lerp

Encoding:
1) Run cloud_march(...)
    Gives: color.rgba, N, F, A, and B
    Note:
        A and B are approximated if 0.33 and 0.67 alpha (respectively) never reached during march.
        A and B will just be 0.33 of F and 0.67 of F respectively.

2) Find M1 and M2 control points that allow normalized cubic to pass through A and B
    d1 = A - N; d2 = B - A; d3 = F - B
    dt = d1 + d2 + d3
    t1 = d1 / dt; t2 = (d1 + d2) / dt

    a = 3 * (1 - t1)^2 * t1
    b = 3 * (1 - t1) * t1^2
    c = 3 * (1 - t2)^2 * t2
    d = 3 * (1 - t2) * t2^2

    det = a * d - b * c
    Note: check det is not zero

    V1 = A - (1 - t1)^3 * N - t1^3 * F
    V2 = B - (1 - t2)^3 * N - t2^3 * F

    M1 = (d * V1 - b * V2) / det
    M2 = (a * V2 - c * V1) / det

    Simplify (normalize between range N and F)
    N = 0; F = 1; A = (A - N) / (F - N); B = (B - N) / (F - N)
    t1 = A; t2 = A + B

    a = 3 * (1 - t1)^2 * t1
    b = 3 * (1 - t1) * t1^2
    c = 3 * (1 - t2)^2 * t2
    d = 3 * (1 - t2) * t2^2

    det = a * d - b * c
    Note: check det is not zero

    V1 = A - t1^3
    V2 = B - t2^3

    M1 = (d * V1 - b * V2) / det
    M2 = (a * V2 - c * V1) / det

Output 2 images (RGBA and RGBA): clouds_low(r, g, b, a) and depth_low(N, F, M1, M2)



Decoding:
Note: Upscaling was done, so clouds_low is now clouds_high and depth_low is now depth_high
Given N, F, M1, M2 from depth_high
Given cloud_color.rgba from clouds_high

1) Get high res lin-depth as d
    Read in depth_high to get N, F, M1, and M2

2) If d < N, cloud obstructed
    Discard and do nothing

3) Get cloud color, as some kind of blending required
    Read in clouds_high to get cloud_color.rgba

4) If d > N and d > F, simple blend
    color.rgb = mix(color.rgb, cloud_color.rgb, cloud_color.a)
    color.a = mix(color.a, 1.0, cloud_color.a);
    Finished

5) If here assume d > N and d < F, decode blend

6) Find t from d:
    t = inv_lerp(N, F, d)
    t = (d - N) / (F - N)

7) Get blend from quadratic bezier
    b = quad_bezier(P0, P1, P2, t)
    b = [(1 - t)^2 * P0] + [2 * (1 - t) * t * P1] + [t^2 * P2]

    Simplify (Encoding normalized between range N and F)
    P0 = 0; P2 = 1; P1 = M1
    b = quad_bezier(0, M1, 1, t)
    b = [(1 - t)^2 * 0] + [2 * (1 - t) * t * P1] + [t^2 * 1]
    b = [0] + [2 * (1 - t) * t * P1] + [t^2]
    b = 2 * (1 - t) * t * P1 * t^2

8) Apply cloud color with blend
    color = mix(color, cloud_color.rgb, cloud_color.a * b)
    color.a = mix(color.a, 1.0, cloud_color.a);
